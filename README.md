# Auvers — Au-delà du tableau

Carnet de visite interactif à Auvers-sur-Oise : parcours, comparaisons entre peintures et lieux, photographies de référence et billet PDF.

Site statique en HTML, CSS et JavaScript, sans compilation. Ouvrir `index.html` ou servir le dossier avec un serveur HTTP local.

Les visuels provisoires et les textes préparatoires sont signalés dans le carnet. Les crédits et licences des photographies, œuvres et vidéo sont disponibles dans le pied de page. Le récit et les photographies personnelles seront complétés après la visite.

La version publiée utilise GitHub Pages depuis la branche `main`, dossier racine.
